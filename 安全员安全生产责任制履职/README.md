# 安全员安全生产责任制履职清单考评表 自动生成工具

一键把空白模板《安全员安全生产责任制履职清单考评表（模板）.doc》生成带当月数据的《安全员安全生产责任制履职清单考评表(X月XXX).doc》：图形化录入 12 个考评项（自评/上级评价），拖拽支撑材料（图片、Word、Excel、PDF 等），由 Microsoft Word 引擎原样填充，输出与手工件版式完全一致。

> **版本**：v1.1.4 ｜ **兼容**：Windows 7 SP1 ~ Windows 11（32 / 64 位） ｜ **运行依赖**：Microsoft Word 2010+（Word 2007 有兼容兜底）

## 功能特性

- **12 个考评项图形化录入**：①安全绩效(20) ②管理体系(10) ③教育培训(5) ④会议活动(5) ⑤检查改进(5) ⑥应急演习(5) ⑦监督执行(5) ⑧安全能力(5) ⑨危险源(5) ⑩隐患排查(5) ⑪违章管理(20) ⑫其它(10)，逐项提供「自评描述 / 自评得分 / 材料说明 / 支撑材料 / 评价描述 / 上级评分」；
- **支撑材料拖拽**：任意文件，每格最多 15 个；图片显示缩略图，其他文件显示 📄 文件名；双击预览打开源文件、右键删除单个、悬停显示完整文件名；
- **文件夹自动匹配**：拖入当月支撑材料文件夹（或年度根目录，按界面年月自动定位当月子文件夹如 `2026.08`），按 `material_rules.json` 文件名权重自动匹配、排序填入 12 项；
- **考评表读取复用**：选择已生成的考评表(.doc)，自动读取姓名/月份、12 项**自评描述/自评得分/评价描述/上级评分**与**支撑材料**（图片、Excel、Word 等内嵌文件全部提取还原），回填界面后可直接替换材料、改月份再生成新表；
- **履职履责表评分读取**：选择月度履职履责表(.xlsx)，按「安全员月度履职评价表」sheet 自动读取所选安全员的 12 项评分与扣分说明，填入各考评项「自评得分 / 自评描述」；文件含多个安全员时弹出姓名选择框；
- **一键生成**：后台打开 Word 填充，界面不卡顿，进度条逐项推进，自动计算自评/上级合计，完成后可一键「打开文件 / 打开所在文件夹」；
- **格式保真**：模板只读、生成使用副本；单元格 Range 文本替换保留原格式；图片内嵌并等比缩放（长宽均 ≤ 2cm）；其他文件嵌入为 OLE 对象（图标+文件名，双击打开），失败自动退化为文件名文字；
- **体积控制**：超大图片嵌入前自动压缩（边长 ≤1600px），生成文档更小、打开更快；非图片材料（Excel/Word/PDF 等）按 OLE 整文件嵌入，生成体积过大时程序会提示；
- **免安装分发**：单 exe + 外置模板即可运行，无需 Python 环境；Win7 纯净系统内置 UCRT，未打补丁也能直接运行。

## 快速开始

### 方式 A：直接使用 exe（最终用户，推荐）

1. 将 exe 与模板放在同一目录：
   - 64 位系统：`dist\安全员履职考评表生成工具.exe`
   - 32 位系统或不确定位数：`dist\安全员履职考评表生成工具_win32.exe`（32 位版在 32/64 位系统均可运行，老 Win7 首选）
   - 模板：`安全员安全生产责任制履职清单考评表（模板）.doc`
2. 双击 exe 启动，按「使用方法」操作即可。

### 方式 B：源码运行（开发环境）

需要 Python 3.8.10（依赖见「开发环境」），在项目根目录执行：

```bash
python generate_kaoping.py
```

## 使用方法

### 第 1 步：填写顶部「基本信息」

| 项 | 说明 |
|----|------|
| 年份 / 月份 | 生成文件与表头「评价月份」所用（默认当前年/月） |
| 姓名 | 手填，写入表头「考评对象」与文件名 |
| 命名模板 | 文件名规则，占位符：`{Y}`=年、`{X}`=月、`{XXX}`=姓名；默认 `安全员安全生产责任制履职清单考评表({X}月{XXX}).doc` |
| 模板文件 | 默认自动定位 exe/程序同目录或其上一级目录；可点击/拖入更换 |
| 输出目录 | 生成文件保存位置（记忆上次路径） |
| 支撑材料文件夹 | 点击/拖入当月文件夹，或选年度根目录（按年份/月份自动定位当月子文件夹） |
| 读取考评表 | 点击/拖入已生成的考评表(.doc)（如 `安全员安全生产责任制履职清单考评表（孙忠7月）.doc`），自动读取姓名/月份、12 项评分与评价、支撑材料（图片/OLE 文件提取还原），回填界面后可替换材料、改月份再生成 |
| 履职履责表 | 点击/拖入月度履职履责表(.xlsx)（如 `2026年履职履责表7月（兴达炼铁保产事业部）.xlsx`），按「安全员月度履职评价表」sheet 自动填入 12 项**自评得分 + 自评描述（扣分说明）**；文件含多个安全员时弹出姓名选择框 |

> 读取考评表时，支撑材料提取到「输出目录\提取材料」下；图片以显示分辨率导出（作为占位参考，可双击预览后右键删除替换），Excel/Word 等文件按原始文件还原。

### 第 2 步：录入中部「12 个考评项」

每项可填写：

- **自评描述**：该项履职情况文字说明；
- **自评得分**：默认等于标准分，有扣分时改为实际得分（0~标准分）；
- **材料说明**：自评实绩材料列的补充文字（可留空）；
- **支撑材料**：拖拽任意文件到蓝色区域（或点击「选择材料」），每格最多 15 个；图片→缩略图，其他文件→📄 文件名；**双击预览打开、右键删除单个、悬停显示完整文件名**；「清空材料」删除该项全部材料；
- **评价描述 / 上级评分**：评价人员填写（可留空，留空交回人工手签）。

> 中部列表支持鼠标滚轮滚动（悬停任意一项即可）。

### 第 3 步：底部工具栏

- **支撑材料文件夹**：也可在底部拖入文件夹/年度根目录自动匹配填入 12 项；
- **编辑权重**：用记事本打开本地 `material_rules.json` 调整关键词，保存后重启程序生效；
- **清空全部**：清空所有填写内容；
- **一键生成**：自动校验（姓名、年月范围、得分范围、模板结构）→ 后台打开 Word 填充 → 进度条逐项推进 → 完成后显示耗时并询问「打开文件 / 打开文件夹」。

### 生成结果

- 输出 `.doc`，与手工件版式一致（宋体 10pt 单元格、黑体 12pt 表头）；
- 表头自动填入考评对象姓名、评价月份；
- 12 项自动填入自评描述/自评得分/自评实绩材料（文字+图片/OLE）/评价描述/上级评分；
- 图片与 OLE 图标显示尺寸统一控制在 **2cm 以内**（含浮点容差），不会撑破表格版式；超大图片嵌入前自动压缩；
- 合计行自动求和；程序同目录生成 `kaoping.log` 便于排障。

## 配置文件

| 文件 | 作用 | 维护方式 |
|------|------|----------|
| `kaoping_config.json` | 记忆输出目录、命名模板 | 程序自动读写，无需手工编辑 |
| `material_rules.json` | 12 个考评项的文件名关键词；**第 1 词权重 2、其余权重 1** | 首次运行自动生成；点「编辑权重」用记事本编辑，保存后重启生效 |
| `kaoping.log` | 运行日志（时间/级别/信息） | 程序自动追加 |

## 模板文件

- 模板由甲方提供，程序**只读不写**，生成时使用副本操作，模板原件安全；
- **模板外置、不内置进 exe**，自动定位顺序：
  1. 界面手动选择/拖入的路径；
  2. exe 所在目录（源码运行时为脚本所在目录）；
  3. exe 所在目录的上一级目录；
  4. 旧版 exe 内置资源目录（`_MEIPASS`，兼容旧产物）。
- 分发时请将模板与 exe 放同一目录；
- 程序会校验模板结构（期望 16 行 × 10 列、表头含「考评对象」「评价月份」），防止模板被换后错格写入；
- 若模板行结构有变，需同步更新 `kaoping_core.py` 中的 `ITEM_ROWS` 映射。

## 构建打包

需要 Win7~Win11 兼容构建环境（版本锁定，见「开发环境」）：

```bash
# 32 位版（32/64 位系统均可运行，老 Win7 首选）——默认
python _build_win7.py

# 64 位版（64 位系统专用）
$env:PYI_BITS="64"; $env:PYI_EXE_NAME="安全员履职考评表生成工具"
python _build_win7.py
```

- `_build_win7.py` 调用 PyInstaller 5.13.2 执行 `安全员履职考评表生成工具.spec`；
- spec 将 Win7 运行时整套文件打进 exe（`ucrtbase.dll` + downlevel `api-ms-win-*.dll`），纯净 Win7 免补丁运行；
- `upx=False` 避免杀软误报；构建中间文件在 `%TEMP%`，产物输出到 `dist\`；
- 模板外置、不打包进 exe。

## 扩展为其他岗位（作业长、班组长、主要负责人）

本项目按"安全员"岗位参数定制，未来可为作业长、班组长、主要负责人等岗位复用同一架构。扩展时只需替换以下"岗位参数"，核心流程与代码不变：

| 岗位参数 | 位置 | 安全员（当前值） |
|----------|------|------------------|
| 空白模板文件 | 外置 .doc | `安全员安全生产责任制履职清单考评表（模板）.doc` |
| 考评项清单（编号/名称/标准分） | `generate_kaoping.py` 的 `ITEM_LABELS` | 12 项（合计 100 分） |
| 考评项 → 表格行映射 | `kaoping_core.py` 的 `ITEM_ROWS` | 1→R3、2→R5、…、12→R15 |
| 表格总行数 / 表头行 | `TOTAL_ROW` / `HEADER_ROW` | 16 / 1 |
| 表头标签 | `_fill_header` / `_replace_slot` | 「考评对象（安全员）：」「评价月份：」 |
| 默认命名模板 | `DEFAULT_NAME_PATTERN` | `安全员安全生产责任制履职清单考评表({X}月{XXX}).doc` |
| 文件名权重 | `material_rules.json` | 12 组关键词 |

参数化方案、演进路线与各岗位需求收集清单详见《技术方案.md》第四章。

## 常见问题

| 问题 | 处理 |
|------|------|
| 提示"找不到模板文件" | 将模板放到 exe/程序同目录（或其上一级目录），或点「模板文件-选择」手动指定 |
| 提示"模板表格结构异常" | 模板被替换/改版（期望 16 行×10 列），换回正确模板 |
| 支撑材料自动匹配不准 | 「编辑权重」调整 `material_rules.json`（同义关键词一并加入），保存后重启程序生效；未匹配文件手动拖入对应项 |
| Word 未安装 | 程序依赖 Microsoft Word，请先安装 |
| 生成时 Word 有弹窗 | 程序已设置 DisplayAlerts=0；首次使用请允许 Word 初始化 |
